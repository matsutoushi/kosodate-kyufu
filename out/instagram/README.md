# Instagram 素材

投稿するものはすべてここに入っています。生成し直しても構造が崩れないよう、
出力先は `pipeline/` の各スクリプト側で固定してあります。

| フォルダ | 中身 | 作り直すコマンド |
|---|---|---|
| `reels/` | リール動画。**いま主力はこちら** | `python pipeline/reel.py` |
| `carousels/` | カルーセル画像 | `python pipeline/carousel.py` |
| `icon/` | プロフィール画像 | `python pipeline/icon.py` |

## reels/

1本1フォルダ。中身は必ずこの3点セットです。

- `video.mp4` … 投稿する動画（1080×1920）
- `cover.png` … カバー画像。**投稿時に必ず指定する**（自動選択させない）
- `caption.txt` … そのままコピーして貼るキャプション

フォルダの連番は投稿順です。次に何を出すかは `reels/README.md` を見てください。

## icon/

- `PROFILE-icon.png` … **アップロードするのはこれだけ**
- `_candidates/` … 不採用案（比較用に残してあるだけ）

## 補足

- カルーセルは新規アカウントではフォロワー外にほぼ届きません（実測1〜2ビュー）。
  リールは同時期に139ビュー。当面はリールを優先します。
- 検証用に書き出した中間画像はここに置きません（プロジェクトが散らかるため）。
