正直に言うと: 副業サイトの多くは「1〜3か月目」で止まります。 伸びるかどうかを分けるのは記事の量ではなく、Instagramを続けられるかです。 上の表の「うまくいけば」は、週2〜3回の投稿を1年続けられた場合の話です。

4. この試算の弱点(隠さずに)

  • Instagram→サイトの導線は弱い。 投稿に直接リンクを貼れず、プロフィールのリンク頼み。既存Xサイトの実測でも流入転換は約1%でした。
  • 読者と購買者がズレる。 「児童手当を調べたい人」がクレカを作る率は低い。だから単価の高いクレカを主軸に置いた計画は当てが外れやすいです。
  • ふるさと納税は季節商売。 11〜12月に大きく偏ります。年間で均すと月あたりは小さく見えます。
  • AdSenseは天井が低い。 月3万円を広告だけで出すには約10万PVが必要で、後発のこのジャンルでは非現実的です。
  • SEOは当てにできない。 公金・お金の情報は Google が信頼性を重視する領域(YMYL)で、個人の後発サイトが検索上位を取るのは困難です。
だからこその設計: 収益はアフィリエイト(比較ページ)、集客はInstagram、 差別化は「全1,740市区町村の医療費データ」のような他がやっていない具体性。 広告収入は“下支え”として後から足す、という順番になります。
